# GasSafe AI

A gas safety PDF research assistant using
Retrieval-Augmented Generation (RAG).

## Technology

- Streamlit
- Qwen2.5-1.5B-Instruct
- MiniLM embeddings
- ChromaDB
- Python
- Docker

## Deployment

This configuration is for a future
Hugging Face Spaces deployment.

The application is not deployed yet.

## Safety

Use only public or synthetic PDFs.

Do not upload confidential documents.

AI-generated answers must be verified
against approved safety manuals.

GasSafe AI is not a certified gas
safety decision system.
